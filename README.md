# 맥널티커피 스마트스토어 대시보드

## 데이터 갱신하는 법

1. 스마트스토어 통계에서 엑셀을 내려받습니다. **파일명은 바꾸지 않습니다** (파일명 속 `YYYYMMDD-YYYYMMDD` 기간을 읽습니다).
   - `sales_…xlsx` 판매분석 (필수)
   - `visit_…xlsx` 유입·방문, `query_…xlsx` 검색어, `cust_…xlsx` 고객(신규·재구매) — 있으면 함께
2. 저장소의 `data` 폴더 → **Add file → Upload files** → **Commit changes**.
3. 1~2분 뒤 자동으로 `index.html`에 반영됩니다 (진행 상황: 위쪽 **Actions** 탭).

- 달마다 따로 쌓입니다. 이번 달은 1일~어제 기간으로 받아 올리면 그 달 데이터가 바뀌고, 지난 달은 그대로 남습니다.
- 같은 달 파일이 여러 개 있으면 **종료일이 가장 늦은 파일**을 씁니다. 예전 파일을 지우지 않아도 됩니다.
- 지난 달 숫자를 고치려면 그 달 파일(예: `sales_20260901-20260930_…`)을 올리면 됩니다.
- 고객(cust) 파일은 여러 달이 한 파일에 들어 있어도 되고, 같은 달이면 나중 기간 파일이 우선입니다.

## 광고분석 (광고비) 갱신하는 법

1. 네이버 광고주센터에서 **검색 광고**, **디스플레이 광고** 각각 '전체 캠페인' 화면으로 갑니다.
2. 기간을 그 달(예: 11/1~11/30, 이번 달이면 1일~어제)로 맞추고, 열 설정에 `기여전환수·기여전환매출액(마지막클릭·데이터기반)`을 켠 뒤 **다운로드**합니다.
3. 두 파일을 `YYYY-MM` 이름의 폴더(예: `2026-11`)에 넣고, GitHub `data/ads` 폴더에서 **Add file → Upload files**로 폴더째 끌어다 올립니다.
   - 파일 이름은 상관없습니다. 행마다 '광고 구분'으로 검색광고(SA)·디스플레이(GFA)를 나눕니다.
   - 같은 달 파일을 다시 올리면 같은 캠페인은 파일명이 뒤쪽(나중 다운로드)인 값으로 바뀝니다.
4. 하루 평균은 그 달 스토어 판매 데이터 일수로 나눕니다. 판매 파일과 광고 파일 기간을 맞춰 주세요.

## 비밀번호

- 대시보드는 비밀번호를 입력해야 열립니다. 데이터는 비밀번호로 암호화돼 있어서, 비밀번호 없이 `index.html` 을 받아도 내용을 볼 수 없습니다.
- 자동 갱신(Actions)이 동작하려면 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 이름 `DASHBOARD_PASSWORD`, 값에 비밀번호를 넣어 둬야 합니다.
- 비밀번호를 바꾸려면: 로컬에서 `DASHBOARD_PASSWORD=기존비번 python page_crypt.py decrypt` → `DASHBOARD_PASSWORD=새비번 python page_crypt.py encrypt` 후 커밋하고, Secret 값도 새 비밀번호로 바꿉니다.
- 주의: 저장소가 공개라서 `data` 폴더의 엑셀 원본은 그대로 공개돼 있습니다. 비밀번호는 대시보드 화면만 막습니다.
